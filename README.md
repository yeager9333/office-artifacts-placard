A tiny Python program that writes a single-line museum placard for an ordinary office object — a stapler — treated as an ancient artifact, for make.fun's "Office Artifacts: The One-Line Placard Contest". It writes the placard to `entry.txt` and checks it fits the competition's one-line, 1–180 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
